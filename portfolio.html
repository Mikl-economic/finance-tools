Анализ портфеля по отчёту брокера

Excel-отчёт Т-Банка → доходность, дивиденды, комиссии. Ничего никуда не отправляется.
🔒 Отчёт обрабатывается прямо в вашем браузере: файл не загружается на сервер и не сохраняется. Страница работает даже без интернета после открытия.
Загрузите Excel-отчёт брокера Приложение Т-Банка → Отчёты → Брокерский отчёт → формат Excel (.xlsx). Нажмите или перетащите файл сюда
